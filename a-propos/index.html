À propos de navi

navi est une encyclopédie indépendante et gratuite. Voici comment elle est faite.

Par Claude (IA, Anthropic) · mis à jour le 29 septembre 2026 · 1 min de lecture

L'auteur : Claude

Les textes de navi sont rédigés par Claude, un modèle d'intelligence artificielle développé par Anthropic. L'éditeur du site a choisi de rester anonyme ; il a défini le projet, fourni des dossiers de recherche et décide de la publication.

Méthode

  1. Dossiers de base : cinq rapports de recherche sur la situation géopolitique mondiale en 2026, le panorama des menaces, la Belgique dans l'ordre mondial et la géosociopolitique belge.
  2. Recherche complémentaire : vérification et actualisation de points clés (gouvernement bruxellois, population, négociations en Ukraine, mobilisations sociales) à partir de sources publiques en septembre 2026.
  3. Croisement : les chiffres divergents entre sources sont signalés ou attribués (« selon… »). Les évaluations contestées (par exemple les classements de V-Dem) sont présentées comme telles.
  4. Structure multi-échelle : chaque dossier situe son sujet aux niveaux macro, méso et micro.

Limites

  • Un modèle d'IA peut commettre des erreurs : vérifiez les chiffres importants auprès des sources primaires citées.
  • Certaines sources des dossiers de base sont secondaires (presse, synthèses) ; les sources officielles sont privilégiées quand elles existent.
  • Les données évoluent : l'état des connaissances est celui de fin septembre 2026.

Neutralité

navi n'est affilié à aucun parti, gouvernement ou groupe d'intérêt. Sur les sujets disputés, le site présente les arguments des différentes parties et attribue les jugements à leurs auteurs.

Licence

Les textes sont publiés sous licence Creative Commons BY-SA 4.0. Les vidéos intégrées restent la propriété de leurs auteurs.

Vie privée

Aucun traceur, aucun cookie publicitaire, aucune mesure d'audience. Les polices sont chargées depuis Google Fonts. Les vidéos YouTube ne se chargent qu'au clic, depuis le domaine youtube-nocookie.com. Le choix de thème (clair/sombre) est mémorisé localement dans votre navigateur.

Technique

Site statique en HTML pur (approche JAMstack), hébergé sur GitHub Pages. Données structurées schema.org en JSON-LD sur chaque page (Article, CollectionPage, BreadcrumbList, DefinedTermSet, FAQPage, VideoObject), plan du site XML, flux Atom, recherche plein texte côté client, accessibilité (navigation clavier, contrastes, lien d'évitement).
